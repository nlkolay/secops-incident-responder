# Netfilter Security Sentinel (SOAR Incident Responder) 🛡️

Легковесный агент безопасности и автоматического реагирования на инциденты (Security Orchestration, Automation and Response) для операционных систем семейства Linux.

Сервис отслеживает системные журналы аутентификации в реальном времени, обнаруживает атаки методом перебора паролей (Brute-Force) и попытки несанкционированного сканирования, автоматически блокирует сетевые адреса нарушителей на уровне ядра с помощью `nftables` и отправляет структурированные оповещения в Telegram.

## 🏗️ Архитектура решения
```
┌─────────────────────────┐
│ /var/log/auth.log       │
└───────────┬─────────────┘
            │ Потоковое чтение событий из журнала
            ▼
┌─────────────────────────┐
│ sentinel.py (Daemon)    │
│ 1. Регулярные выражения │
│ 2. Проверка whitelist   │
│ 3. Скользящее окно атак │
└─────┬──────────────┬────┘
      │              │
      │ Блокировка   │ HTTP POST (TLS)
      ▼              ▼
┌──────────────┐ ┌──────────────────────┐
│ nftables     │ │ Telegram Bot API     │
│ Set timeout  │ │ Канал оповещений ИБ  │
└──────────────┘ └──────────────────────┘
```

## ⚙️ Особенности и преимущества

* **Отсутствие внешних зависимостей:** Работает на стандартной библиотеке Python 3. Не требует пакетных менеджеров и компиляторов.
* **Высокопроизводительная блокировка (nftables sets):** Сетевые адреса заносятся в хэш-таблицу ядра с автоматическим временем жизни (TTL). Проверка пакетов происходит со сложностью O(1) без снижения пропускной способности интерфейса.
* **Защита от подмены и инъекций:** Все извлеченные адреса валидируются встроенным модулем `ipaddress`. Некорректные данные или попытки внедрения команд игнорируются.
* **Исключение ложных блокировок (Whitelist):** Локальные подсети (RFC 1918) и адреса локальной петли защищены от бана на программном уровне.
* **Устойчивость к ротации журналов (Logrotate):** Демон отслеживает смещение дескрипторов и переоткрывает файл при архивации.

## 🚀 Установка и настройка

### 1. Клонирование репозитория
```bash
git clone https://github.com/nlkolay/secops-incident-responder.git /opt/sentinel
cd /opt/sentinel
```
### 2. Конфигурация
Наполните файл конфигурации config.json.
### 3. Настройка службы systemd
Для обеспечения непрерывной работы создайте системную службу:
```
cp sentinel.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now sentinel.service
```

##📊 Проверка работы

Просмотр заблокированных адресов в ядре Linux:
`nft list set inet sentinel blacklist`

Ручной просмотр журнала работы службы:
`journalctl -u sentinel.service -f`
